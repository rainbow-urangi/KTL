REFERENCE · mock-dataset-01 · 합성 count 예시

Raw counts를 보내고 실제 서버 응답을 확인하세요.

기존 M01/M04/M07 endpoint를 호출합니다. 서버가 점수를 계산하며 성공 응답은 HTTP 201 Created입니다. official_pass는 null입니다.

요청 JSON의 counts와 details를 편집할 수 있습니다. 전송·복사 시 고유 mock ID와 제출 시각을 갱신합니다. OFFICIAL 전송은 허용하지 않습니다.

부분 사례는 details.example_cases에 넣습니다. 최상위 cases를 사용한다면 전체 분모 건수를 포함해야 합니다.

실제 요청은 REFERENCE 결과 파일과 해당 지표의 latest에 저장됩니다. 화면의 Sample Response는 예시이며, 실제 응답은 전송 후 별도로 표시됩니다.
