KTL 검토용 근거 CSV (읽기용 형식)

대상은 M01·M04·M07입니다. M02·M03·M05·M06의 요약/개별 판정/원본
식별 구조를 참고했으며 네 항목의 코드·산식·CSV는 변경하지 않았습니다.
이 형식은 읽기 편의를 위한 추가 산출물이며 KTL이 지정한 공식 서식은 아닙니다.

열 순서

구분 / 번호 / 업무 / 항목 / 기대 / 결과 / 판정 /
분자 / 분모 / 측정값 / 단위 / 근거

정보에는 실행 ID, 시간대가 확인된 KST 시각, 평가 구분, 출처와 원본
근거 위치를 기록합니다. 요약에는 산식의 분자·분모와 보관 점수를 표시하고
그 아래에 개별 이벤트·시나리오·코드의 결과를 둡니다. 값이 없거나 평가가
끝나지 않은 경우 측정값을 0이나 PASS로 채우지 않습니다.

파일은 Excel에서 한글을 읽을 수 있도록 UTF-8 BOM을 사용하며 모든 행은
같은 12열입니다. 셀 내부 개행과 중첩 JSON을 제외합니다. CSV는 글꼴·열 너비·
색상·필터 같은 Excel 서식을 저장하지 않습니다. 측정값은 소수점 2자리로
표시하지만 목표 충족 판정은 원래 평가 결과를 사용합니다. 정확한 원본 수치와
로그·필드·해시는 기존 상세 근거에 보관됩니다.

M01

기존 원본 evidence.csv를 재계산해 검산한 뒤 읽기용 CSV를 내보냅니다.
C1 수집수/필수수, C2 누락필드수/전체필드수, C3 관측유형수/정의유형수,
최종 가중점수, 필수 이벤트별 수집/누락, 필드 누락, 유형 집계를 구분합니다.
미분류 이벤트도 집계해 전체 수집 건수와 맞추되 C3의 정의 유형수에는 넣지 않습니다.
공식 판정과 업무 완료·내용 정확성을 새로 추정하지 않습니다.

읽기용: /api/development/m01/comparisons/<comparison_id>/ktl-evidence.csv
기존 원본: 같은 경로의 evidence.csv
기존 검산: 같은 경로의 verification

M04

현재 실행 결과의 요약과 시나리오별 성공/실패, 업무 단계, 확인 조건을
내보냅니다. 브라우저 추적 수천 행과 중첩 로그는 원본 steps.csv에 남깁니다.
단건·부분 실행을 10건 완료로 표시하지 않습니다. 진행 중이거나 집계가
일치하지 않으면 최종 측정값을 비워 둡니다. 입력값·선택자·원시 오류 원문은
읽기용 CSV에 넣지 않습니다.

읽기용: /api/development/m04/executions/<execution_id>/artifacts/ktl-evidence.csv
기존 원본: 같은 artifacts 경로의 steps.csv, report.json 등
기본 Evidence CSV 버튼을 읽기용 경로에 연결하고 추가 근거 링크는 유지합니다.
외부 접수 결과의 버튼은 기존 접수 evidence.csv를 사용합니다.

M07 기존 코드 10건 문법검사

지정한 M07-CHECK 실행 ID의 보관 결과와 고정 원본 코드의 해시를 확인하고
문법 통과율, 고정 분모 10, 문법 정상/오류, 기존 판정과의 일치 여부를 내보냅니다.
새 GPT 요청·재검사·코드 실행·브라우저 시작을 수행하지 않습니다.
기존 판정과 오류가 일치해도 문법 통과로 계산하지 않습니다.
이 파일은 기존 코드 문법검사 자료이며 공식 20건 문법·실행 통합 평가가 아닙니다.

읽기용: /api/development/m07/existing-codes/checks/<run_id>/ktl-evidence.csv
원본: data/development/m07_existing_checks/<run_id>.json
원본 문제·코드·계약: data/development/m07_existing_codes/의 고정 묶음
결과가 없거나 원본 해시·보관 집계가 다르면 내보내기를 거부합니다.

보존 및 접근

결과는 M01 수집/누락, M04 성공/실패/대기, M07 정상/오류로 표시합니다.
목표 충족 여부는 통과/미달/대기, 검산은 일치/불일치로 표시합니다.
평가 구분은 개발, 공식 합격 여부는 미판정으로 표시하며 원래 상태 값은
근거에 유지합니다. 시각은 M01 비교시각, M04 완료시각(진행 중은 시작시각),
M07 검사시각으로 구분합니다. 업무명·조건·분모·수치·해시는 줄이지 않습니다.

다운로드는 원본 결과·점수·분모·평가 기준을 수정하지 않습니다.
M01/M04는 기존 서버 세션별 접근 제한을 따릅니다. 재시작 전의 기록이 새
화면에서 보이지 않는 것과 파일이 삭제된 것은 다릅니다.
M07 기존 문법검사 다운로드는 특정 run_id로 고정되므로 latest가 바뀌어도
다른 결과를 대신 내려주지 않습니다.
